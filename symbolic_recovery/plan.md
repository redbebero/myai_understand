# 가중치 기반 수식 복원 실험 계획

## 질문

학습 데이터와 정답 라벨을 보지 않고, 학습된 모델의 구조와 가중치만 분석해 더 단순한 수학식과 코드로 바꿀 수 있을까?

## 제한 조건

- `two_spiral/spiral_model.json`의 구조, 가중치, 편향, 활성화 함수만 사용한다.
- `two_spiral`의 데이터 생성 코드와 라벨은 수식 탐색 단계에서 사용하지 않는다.
- 입력 좌표는 실험 코드가 직접 무작위로 만든다.
- 최종 수식이 결정된 뒤에만 실제 라벨로 정확도를 확인한다.

## 실행 순서

1. 기존 모델 가중치를 `target_model.json`으로 복사한다.
2. 모델을 실행해 입력 좌표와 출력 확률만 기록한다.
3. `x`, `y`, 반지름, 각도, 삼각함수 등 일반적인 후보 함수를 만든다.
4. 후보 수식의 계수와 주파수를 탐색한다.
5. 모델 출력과 가장 잘 일치하면서 가장 짧은 수식을 선택한다.
6. 탐색에 사용하지 않은 입력으로 수식과 모델의 일치율을 확인한다.
7. 마지막에만 실제 라벨을 사용해 분류 정확도를 비교한다.

## 성공 기준

- 수식 탐색 단계에서 라벨 파일을 읽지 않는다.
- 선택된 수식이 숨겨둔 입력에서 기존 모델의 분류와 높은 일치율을 보인다.
- 수식이 신경망보다 짧고 사람이 읽을 수 있다.
- 모델 출력과 수식 출력의 차이와 한계를 기록한다.

## 예상 가능한 결론

- 성공: 이 모델의 통계적 판단을 더 단순한 수학적 구조로 근사할 수 있다.
- 부분 성공: 특정 결정 경계만 단순화할 수 있다.
- 실패: 가중치만으로는 단순한 수식을 찾기 어렵고, 추가적인 데이터 구조 해석이 필요하다.
