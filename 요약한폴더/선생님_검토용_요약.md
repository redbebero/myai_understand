# 선생님 검토용 연구 요약

## 연구 제목

**신경망의 내부 representation geometry는 직접 설계되는가, 아니면 반복적인 gradient feedback으로 형성되는가?**

## 검토받고 싶은 핵심 질문

UCI HAR 데이터의 `561→64→32→6` MLP에서 사람이 hidden layer의 class geometry를 직접 지정하면 학습을 대신할 수 있는지 확인하고자 했다.

현재 가장 중요한 질문은 다음과 같다.

> 일반화 가능한 representation은 초기 gradient나 사람이 정한 geometry만으로 만들 수 있는가? 아니면 representation이 바뀔 때마다 gradient를 다시 계산하는 iterative feedback이 필요한가?

## 왜 이 질문을 선택했는가

처음에는 중요한 뉴런이나 feature를 찾으면 AI의 판단을 설명할 수 있을 것이라고 생각했다. 그러나 seed가 바뀌면 중요한 뉴런 번호가 달라졌고, 개별 뉴런만으로는 판단을 안정적으로 설명할 수 없었다.

그래서 질문을 다음처럼 바꾸었다.

```text
어떤 뉴런이 중요한가?
→ 어떤 내부 geometry가 판단을 만드는가?
→ 그 geometry를 사람이 직접 만들 수 있는가?
→ gradient training은 geometry를 어떻게 형성하는가?
```

## 실험 조건

- UCI HAR 원본 입력 561개
- MLP: `561→64→32→6`
- strict train/validation/test 분리
- 5개 seed: `7, 11, 19, 23, 31`
- Adam cross-entropy
- test는 update 설계에 사용하지 않음
- 새 feature 또는 neuron 탐색 없음

## 핵심 비교 실험

동일한 초기화, 동일한 128개 sample, 동일한 순서를 사용했다.

1. **One-shot averaging**: 초기 128개 gradient의 평균을 한 번 적용
2. **Frozen-gradient sequential**: 초기 gradient를 저장하고 계속 적용
3. **Recomputed sequential**: 매 update 후 현재 모델에서 gradient를 다시 계산

## 핵심 결과

| 방법 | Test accuracy | Test loss | 동일 parameter norm 후 accuracy |
|---|---:|---:|---:|
| One-shot averaging | 0.279 | 1.846 | 0.356 |
| Frozen-gradient | 0.338 | 9.544 | 0.342 |
| Recomputed gradient | 0.706 | 0.768 | 0.698 |

Recomputed 방식에서 현재 sample gradient와 같은 sample의 초기 gradient 사이 cosine은 평균 `0.350`, 마지막에는 `0.234`였다. 즉 representation이 변하면 이후에 필요한 gradient 방향도 변했다.

## 현재 결론

초기 gradient를 한 번 계산해 사용하는 것만으로는 최종 representation을 설명하기 어렵다. 사람이 지정한 centroid나 overlap geometry도 validation 목표에는 맞출 수 있지만 test 분포 전체를 안정적으로 개선하지 못했다.

현재 데이터에서 가장 잘 맞는 최소 원리는 다음과 같다.

```text
현재 representation
→ 현재 분류 오차
→ gradient
→ parameter 변화
→ 새로운 representation
→ 새로운 gradient 재계산
→ 반복 trajectory
→ unseen data에 공유되는 geometry
```

따라서 이 연구의 주장은 “새 optimizer를 발견했다”가 아니다. **정적인 geometry를 직접 설계하는 방식이 왜 일반화에 실패하는지, 그리고 representation 상태를 반영한 반복적 gradient feedback이 왜 필요한지 비교 검증했다**는 것이다.

## 한계

- UCI HAR 한 데이터셋만 사용했다.
- MLP 구조 하나만 사용했다.
- 최종 feedback 비교는 동일한 128개 sample을 사용한 통제 실험이다.
- 따라서 딥러닝 전체에 대한 보편 법칙이라고 주장할 수는 없다.
